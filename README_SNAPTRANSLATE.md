# SnapTranslate

SnapTranslate 是基于 [eSearch](https://github.com/xushengfeng/eSearch) 定制的跨平台截图翻译工具，支持 macOS 与 Windows。

## 已包含的功能

- 区域、全屏与滚动截图，及标注、马赛克、模糊、贴图和录屏
- 本地 PaddleOCR 文字识别
- 截图后的文字翻译与贴图式屏幕翻译
- OpenAI 兼容的翻译 API（密钥仅保存在本机应用设置中）

## 配置自己的 AI 翻译 API

启动应用后，依次设置：

1. `设置 → 人工智能 → 在线模型 → 添加`。
2. 填写名称、API Key、模型名，以及 API 根地址。例如 OpenAI 使用 `https://api.openai.com/v1/`；自建兼容服务则填写其 `/v1/` 根地址。
3. `设置 → 翻译 → 翻译引擎 → 添加`，选择 `大模型`，并选择刚创建的在线模型。
4. 在 `设置 → 翻译` 中设置源语言和目标语言；第一个翻译引擎会作为截图翻译与屏幕翻译的默认引擎。

## 常用操作

- 通过全局快捷键启动截图，框选后执行 OCR 或翻译。
- 在截图界面选择翻译按钮，即可将 OCR 结果提交至已配置的 AI 引擎。
- 使用“屏幕翻译”可将翻译结果显示为屏幕贴图；也可开启定时翻译。

## 构建

```bash
pnpm install
pnpm run dist
```

macOS 构建产物为 `.dmg` / `.zip`，Windows 请在 Windows 环境执行相同构建命令以生成 `.exe` 安装包。
